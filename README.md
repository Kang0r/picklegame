# 🐰 피클 도망가!

귀여운 픽셀 아트 스타일의 장애물 피하기 게임입니다. 순수 HTML/CSS/JavaScript로만 만들어져 있어 별도 빌드 없이 브라우저에서 바로 실행됩니다.

## 플레이

👉 **[여기서 바로 플레이하기](https://kang0r.github.io/picklegame/)**

## 조작법

- `←` / `→` 방향키 (또는 `A` / `D`): 좌우 이동
- `Space` / `Enter`: 시작 및 재시작

## 게임 방법

하늘에서 무작위로 떨어지는 장애물을 피하면서 최대한 오래 살아남으세요. 시간이 지날수록 장애물이 더 빠르고 자주 떨어집니다.

## 커스터마이징

홈 화면의 **🎨 커스터마이징** 버튼에서 맵(초원 / 바다 / 우주)을 선택할 수 있고, 맵마다 어울리는 캐릭터 스킨과 배경 연출(구름 / 거품 / 별)이 함께 바뀝니다.

## 로컬 실행

빌드 도구가 필요 없습니다. `index.html`을 브라우저로 열기만 하면 됩니다.

```bash
git clone https://github.com/Kang0r/picklegame.git
cd picklegame
# index.html을 브라우저로 열기 (또는 VS Code Live Server 확장 사용)
```
